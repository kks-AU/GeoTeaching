# GeoTeaching
Interactive teaching examples


Åbn `index.html` i en browser. Forsiden og de otte øvelser er statiske og bruger relative stier.

## Udgivelse med GitHub Pages

Læg `index.html`, `eksempler/`, `assets/` og `.nojekyll` i roden af GitHub-repositoriet. Vælg **Settings → Pages → Deploy from a branch** og vælg den branch og rodmappe, der indeholder filerne. [GitHubs vejledning til udgivelseskilder](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Kapitelhenvisninger

Hver øvelse henviser til relevante kapitler, afsnit og sider i *Geoteknik*, 3. udgave.
